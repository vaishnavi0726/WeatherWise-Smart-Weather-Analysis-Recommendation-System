# WeatherWise – Smart Weather Analysis & Recommendation System

> A rule-based smart weather analysis & recommendation system built using R Shiny. No ML/DL used.

## 📖 About
WeatherWise is a simple, fast, and user-friendly system that provides weather data analysis, temperature conversion, and smart recommendations. It runs on local server `127.0.0.1:3064` and is developed for educational and daily use purpose.

## ✨ Features
- **Analyze Weather Data:** Checks Even/Odd count and Average temperature
- **Weather Recommendation:** Gives Weather Type (Hot/Cold), Dress Advice & Rain Advice
- **Celsius to Fahrenheit Converter:** For weather standardization (e.g., 37°C = 98.6°F)
- **Rectangle Area Calculator:** For weather station / farming land area
- **Factorial Calculator:** Calculates factorial from 0 to 20

## 🚀 How to Run
1. Install R and RStudio
2. Install shiny library: `install.packages("shiny")`
3. Run the app: `shiny::runApp()`
4. App will open on `http://127.0.0.1:3064`
